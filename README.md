# Веб-приложение для учета локального запаса продуктов

Данный проект является частью курсовой работы (2026 год) по дисциплине 
**"Проектирование информационных систем"**.

Приложение предназначено для учета запасов продуктов в домашних или небольших
локальных условиях. Оно позволяет вести справочник продуктов и категорий,
фиксировать поступающие партии, отслеживать сроки годности, списывать
испорченные или использованные продукты, а также автоматически формировать
списки покупок на основе дефицита запасов.

## Возможности

- Аутентификация и регистрация пользователей;
- Панель управления с ключевыми показателями и интерактивными графиками:
  - распределение запасов по категориям;
  - топ-5 продуктов с ближайшим сроком годности;
  - динамика списания продуктов за последние 7 дней.
- Ведение склада: просмотр текущих остатков, добавление партий, списание
  товаров с указанием причины (использовано, просрочено, удаление).
- Справочник продуктов: добавление, удаление, указание штрих-кода и
  минимального остатка.
- Управление категориями продуктов.
- Настройка минимального количества для каждого продукта.
- Автоматическая генерация списка покупок по дефициту запасов с возможностью
  отметки купленных позиций.
- Уведомления о продуктах с истекающим (3 дня) и истекшим сроком годности.
- Встроенная консоль базы данных H2.

- JDK 17 или выше;
- Maven 3.6+ (либо использование встроенного в IDE Maven).

## Установка и запуск

Клонируйте репозиторий и перейдите в директорию:

```bash
git clone https://github.com/dydojopka/Local-Stock-Tracker.git
cd Local-Stock-Tracker
```

### Вариант 1. Запуск через Maven

Из корневой директории проекта выполните:

```bash
mvn spring-boot:run
```

После запуска приложение будет доступно по адресу:

```
http://localhost:8080
```

### Вариант 2. Сборка и запуск JAR-файла

Соберите проект:

```bash
mvn clean package
```

Запустите собранный JAR-файл:

```bash
java -jar target/LocalStockTracker-1.0-SNAPSHOT.jar
```

Откройте в браузере:

```
http://localhost:8080
```

## Учетные данные по умолчанию

При первом запуске автоматически создается администратор:

| Параметр | Значение   |
|----------|------------|
| Логин    | `admin`    |
| Пароль   | `admin123` |

Новые пользователи могут зарегистрироваться через форму регистрации. По
умолчанию новым пользователям назначается роль `USER`.

## База данных

Приложение использует файловую базу данных H2, которая хранится в директории
`./db/`. При запуске схема базы данных создается автоматически, а начальные
данные загружаются из файла `src/main/resources/dump.sql`.

Доступ к веб-консоли H2:

```
http://localhost:8080/h2-console
```

Параметры подключения к консоли:

| Параметр | Значение                        |
|----------|---------------------------------|
| JDBC URL | `jdbc:h2:file:./db/course_work` |
| User     | `sa`                            |
| Password | *(пусто)*                       |
